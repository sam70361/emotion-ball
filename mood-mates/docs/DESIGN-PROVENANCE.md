# 设计过程记录 · Design Provenance

> 本文件是 Mood Mates 全部视觉资产的原创证据链：记录每个角色的设计动机、生成方法、参数与迭代过程。所有轮廓均由 `src/core/geometry.js` 的参数化函数实时生成，仓库中不存在任何手绘描摹或第三方来源的坐标数据。

## 一、设计方法论

**日期**：2026-08-20（首版 v1.0；同日 v1.1 精修：概念图定稿、瞳孔眼分层、配饰联动、签名特效、电商 / 金融角色替换；同日 v1.2：四个剪影形象化重构、Peachy 替换 Hearty、小眼瞳孔/高光物理守则）

**核心方法**：全部视觉形状 = 参数化几何基元 + 设计参数。

1. **身体剪影**：以径向函数 r(θ)（96 点采样）或超椭圆参数曲线生成。基元包括：钟形隆起（bump）、扇贝波（scallop）、余弦星形权重、超椭圆等，均为初等数学函数的组合。
2. **眼形**：统一 lens（双缘包络）拓扑——中轴线 mid(u) + 厚度包络 halfThick(u)，上下缘各 24 点。20 个语义槽位（平静 / 笑眼 / 圆睁 / 闭合 / 斜眼 / 怒目 / 扫读 / 聆听 / 羞怯 / 哀伤及变体）是对"眼睛如何表达情绪"这一通用表演语言的参数化实现，每个角色以自己的基调参数（宽高 / 圆度 / 倾角）实例化。
3. **嘴形**：同 lens 拓扑的 24 点小环，9 个语义槽位（smile / grin / o / flat / frown / wavy / pout / open / dot）。
4. **特效**：轨道 / 爆发 / 发射器三类粒子系统（云絮 / 星尘两套皮肤），粒子形状为程序生成的基本图形（圆、多圆拼合云朵、四芒星、五角星、铅笔）；每个角色有一套"签名动作"发射脚本（云絮绽放 / 星星爆闪）。
5. **眼睛分层（v1.1）**：瞳孔眼 = 眼睑 lens 环作 clipPath + 眼白 / 虹膜（径向渐变圆）/ 瞳孔 / 定光源高光分层；闭合感由轮廓"鞋带面积 ÷ 宽度"的实际厚度判定，低于阈值切换为深色睫线。全部为几何构造，无任何图像资产。
6. **工具**：`tools/ring-editor.html`，即本仓库自带的参数化编辑器。设计迭代即调参过程，最终参数直接写入角色数据文件，可随时复现。
7. **概念图（v1.1）**：制作前先以文生图产出高端 3D 风概念稿定调（存于仓库外 assets 记录），再以参数化几何逼近其剪影与配色。概念图仅作为内部气质参考，最终资产均为参数生成。

**独立性声明**：本项目的代码（状态机、弹簧插值、球面投影、配置注册中心）与视觉资产（全部几何生成参数、配色、配饰路径）均为独立创作，未参考、复制或描摹任何第三方美术作品的具体表达。"会做表情的卡通形象"属于不受著作权保护的通用创意；本项目的具体表达（剪影参数、五官体系、配色、配饰、特效语言）均为原创。

## 二、角色档案

### Nimbo 云宝（通用 · 云朵）

- **动机**：默认角色需要最大亲和力与松弛气质；慢半拍性格由表情覆盖实现（待机轮换 12~20s）。概念定稿：雾蓝薰衣草方案。
- **身体**：`{ type:'cloud', r:0.94, lobes:7, amp:0.08, flat:0.12 }` —— 7 瓣奇数扇贝避免对称呆板，底部收平如坐云。
- **眼**：豆眼，月牙感来自 bend 0.1 + tilt -2；gloss 0.2（云朵哑光，弱化釉面）。
- **色**：雾蓝薰衣草 #B4C6EE。
- **签名动作**：云絮绽放——身体四周噗噗冒出一圈蓬松小云朵（多圆拼合的迷你云剪影，左上叠受光提亮，与主体光源一致），每朵带过冲的弹性弹出、摇曳上飘、末段收缩淡出，出生时伴一圈"噗"的空气涟漪，云朵间隙点缀微光四芒星。
- **迭代记录**：v1.0 签名为云底飘雨（重力斜落雨滴），偏安静不成戏；v1.5 短暂尝试过"吞吐彩虹"，最终定稿为云絮绽放——"云生小云"与角色心智最同源，且绕开了嘴部动作对各表情嘴形的适配负担。

### Twinkle 亮亮（通用 · 五角星）

- **动机**："元气小老师"气质，星形 + 圆框眼镜是知识感与亲和力的平衡（v1.3 起行业定位由教育改为通用）。概念定稿：蜂蜜金 + 金框眼镜方案。
- **身体**：`{ type:'star', r:1.02, points:5, inner:0.74, sharp:0.5 }` —— inner 0.74 让星角圆润不扎手。
- **眼**：瞳孔眼（taper 0.38）+ `pupil: { irisR:10, pupilR:4.8, irisColor:#7A4E2A（暖棕）}`。
- **配饰**：autoFit 圆框眼镜（`kind:'glasses'`，fit 1.3，金框 #C9973F）——镜框位置半径由眼位眼形自动求出，追随目光 75%、眨眼下滑回弹、镜片周期扫光。
- **色**：蜂蜜金 #F5B93F；特效星尘（思考轨道混入旋转铅笔，chance 0.3）。
- **面部拟合**：星形中心区域小，face sx/sy 0.82 收紧五官。

## 三、v1.2 迭代记录（2026-08-20）

本版为共享渲染层建立眼睛物理守则（全角色受益）：

- 豆眼高光按有效可见高度隐藏（眯、扫读、困倦不再冒白点），偏移随当前眼环 bbox 缩放并钳制不出眶；
- 瞳孔眼增加小眼档：睫线之下藏虹膜；瞳孔圆心按 bbox 收缩钳制；
- `signatureMouth` 机制上线：签名动作触发时嘴形临时覆盖（如 `o`），到期弹回当前表情嘴形。

同版曾对四个后续下线的角色（水滴 / 火苗 / 蜜桃 / 存钱罐）做剪影形象化重构，相关角色与生成器已在 v1.3 / v1.5 全部移除，不再赘述参数。

## 四、v1.3 迭代记录（2026-08-20）

- **角色阵容精简**：仅保留云宝 Nimbo 与亮亮 Twinkle 两位角色。茉茉 / 焰仔 / 桃桃 / 存存及其替补方案（购物袋 / 金币罐）经评审辨识度与气质均不达标，整体移除。云宝维持豆眼 + 高光的原有眼型，不加眉毛与手脚。
- **轮廓平滑渲染**：`render.js` 的 ringPath 由折线（L 段）升级为 Catmull-Rom → 三次贝塞尔过点样条，身体 / 眼 / 嘴 / 眉全部轮廓在任意缩放下边缘圆润无棱角，几何采样参数不变。
- **自旋动效**：自旋时身体增加轻微角度倾斜（±5°）与横向弹性压缩（0.88~1.0），以"角度翻转"替代此前只有五官滑动的"纸片折叠"观感。
- **豆眼高光一致性**：此前可见高度低于 18px 的眼形一律隐藏高光点，导致眯眼 / 扫读 / 部分小眼表情"没有瞳孔"。改为仅在真正闭眼（<10px）时隐藏，10~26px 区间高光点按比例缩小（最小 0.55 倍），云宝基础高光半径 2.8 → 3.2，全表情瞳点观感一致。
- **展馆布局**：角色选段（cast row）由页面底部移至最上方——位于模式切换与分组 tab 之上（grid 显式分区 cast / head / thumbs），陈列墙与画册两种模式一致，切换角色不再需要滚动到页底。
- **亮亮行业类型**：education → general，与云宝同为通用角色。
- **合并进 emotion-ball 仓库**：本项目以 `mood-mates/` 子目录形式并入 emotion-ball 仓库，自带展示站与全部许可文件；根目录球形角色维持"仅供学习"许可，本项目维持双许可，互不影响。

## 四·五、v1.4 迭代记录（2026-08-20）

- **lens 拓扑重构（眼 / 嘴轮廓质感升级）**：旧实现上下缘各自按 x 均匀铺点后拼合，两端厚度归零处产生一对重合点，过点样条经过重复点会折出肉眼可见的尖角；且端部曲率最大处采样反而最稀。重构为闭合曲线参数化采样（φ 绕行一周，u = (1-cosφ)/2），端点上下缘汇合为单点、采样自然向两端加密——眼形与嘴形的端帽圆润程度达到解析胶囊同级，槽位语义参数（w/h/bend/slope/taper/shift/tilt）与环点数完全不变，全部表情形变兼容。
- **身体轮廓变体机制**（引擎能力）：角色可声明 `variants = { id: { name, en, body } }`，变体仅替换身体剪影 bodyRing，眼形族 / 色板 / 表情编排全部共享；`MoodMates.create` 新增 `variant` 选项。总馆的「形状」下拉即走此入口（球球的三种形态由 EB shape 映射）。
- **云宝「扇贝云」第二轮廓（已删除）**：曾按平涂贴纸风尝试五瓣 / 六瓣深凹口扇贝，五瓣与亮亮的五角星撞形、六瓣观感仍不达标，评审后整体删除，云宝只保留默认七瓣蓬松云；变体机制保留供后续使用。
- **瞳孔眼小眼档不再藏瞳孔**：此前小眼档（有效开合 0.26~0.45）连瞳孔带高光一起隐藏，只留虹膜，导致亮亮眯眼 / 扫读类表情"最深色的瞳点消失"。改为瞳孔与虹膜同进退、按开合度比例缩小（最小 0.6 倍），仅白色高光在小眼档隐藏；睫线档（<0.26，真正闭眼）不变。
- **亮亮移除眉毛**：镜框上方的短杠与瞳孔眼 + 眼镜叠加后面部信息过密，情绪已由眼睑开合 / 视线 / 嘴形充分表达，移除后更贴合简约组合的设计语言。
- **线稿模式不画嘴**：线稿下描闭合嘴环会出现不规则细圈，曾改为中线弧线，最终评审决定线稿只留身体轮廓与眼睑线，不画嘴——更接近手绘草稿的减法表达。
- **点击庆祝组合 `celebrate()`**：单一签名动作作为点击反馈偏单调，新增引擎方法把「签名动作 + 随机自旋或弹跳 + 撒花」打包成一次庆祝，观感与球球的甩带 + 烟花同量级；待机 antics 仍走轻量签名，不受影响。
- **线稿描边色跟随页面主题**：此前线稿描边取体色加深 / 瞳色，在暗色页面上近黑描边几乎不可见。改为优先消费页面 CSS 变量 `--sketch-ink`（暗色页浅墨、亮色页深墨），无主题变量时回退旧逻辑——引擎保持零站点耦合，主题适配交给宿主页定义变量。

## 四·六、v1.5 迭代记录（2026-08-21）

- **云宝签名动作换代**：云底飘雨 → 云絮绽放。飘雨作为点击反馈太安静、方向单一；中途尝试过"吞吐彩虹"（螺旋吸入 + 缎带拱虹），但嘴部吞吐与各表情嘴形的适配成本高、观感也不够贴合角色，最终定稿为云絮绽放：身体四周噗噗绽开一圈小云朵，弹性过冲弹出、摇曳上飘、伴空气涟漪与微光星点。所有粒子锚定身体中心 + 实时身体位移，弹跳 / 自旋 / 任意表情期间均正确跟随，不依赖嘴形。rain / rainbow 皮肤同步移除。
- **最终交付死代码清理**：移除无角色使用的身体生成器（drop / flame / bag / shield / heart / peach / pig，仅留 cloud / star 与通用扩展点 puff）、特效皮肤（bubbles / embers / hearts / coins）、配饰构建器（snout / coinslot / limbs），及站点文案中未使用的行业键；引擎默认皮肤改为 cloudpuff。引擎能力以"现役角色实际使用 + 通用扩展点"为准，不保留空挂能力。
- **形状下拉残留修复**：本地存储中已下线的变体 id（如 scallop）会让 select 匹配不到选项而显示空白，填充时校验并回落默认形状。
- **开屏构图**：半遮罩线稿角色整体放大（720 → 880px）并下沉 7%，只露眉眼以上，配合底边横向渐隐分割线，视觉更聚焦。

## 五、共享表情基座

32 套表情编排（`src/data/emotions.js`）沿用本项目自研的"眼形池 + 动画原语 + 关键帧序列"三层配置格式，参数（时长、幅度、频率）为逐个调校的表演设计。眼形引用语义槽位而非具体几何，颜色引用 @token 而非具体色值——同一编排在每个角色身上呈现各自的长相与色彩。

## 六、后续新增角色

新增角色时请在本文件追加一节角色档案，包含：动机、身体参数、眼形参数、配色、配饰说明、迭代记录（含日期）。这是持续维护原创证据链的要求，也是 `docs/CHARACTER-DESIGN.md` 规范的一部分。
